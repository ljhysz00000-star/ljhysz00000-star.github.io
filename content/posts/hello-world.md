欢迎来到我的博客！这是用 **Hugo** + **FixIt** 主题搭建的第一篇文章。

## 这篇是示例

你可以直接编辑 `content/posts/` 目录下的 Markdown 文件来写新文章，或者运行：

```bash
hugo new content posts/my-new-post.md
```

## 支持的能力

FixIt 主题自带不少开箱即用的能力：

- 明暗主题切换
- 代码高亮
- 数学公式（KaTeX）
- 站内搜索
- 目录（TOC）
- 标签 / 分类

把这篇内容换成你自己的文字，就可以发布了。
